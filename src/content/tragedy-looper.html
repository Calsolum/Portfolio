Board Game Companion · Browser Tool

Tragedy Looper is one of the most complex deduction board games ever designed. Keeping track of it is the hard part. This app handles that.

Built as a single self-contained HTML file, the Tragedy Looper Digital Mastermind Companion replaces the physical board, tokens, card hands, and rulebook lookup entirely. One Mastermind. Three Protagonists. Thirteen official scripts preloaded from the New Tragedies rulebook, each with full cast, secret roles, starting locations, and incident schedules.

Characters move between locations via drag-and-drop on desktop and a custom touch-drag system on mobile. Token counts update in real time. Card plays are logged, daily limits enforced, and once-per-loop restrictions tracked automatically. All 28 named characters have their Goodwill abilities coded with cost thresholds, mechanical effects, and guided prompts for complex ones.

The win condition engine derives loss conditions from the active script and tracks progress as board state changes — so the Mastermind always knows exactly how close the Protagonists are to winning without having to count manually.

Zero dependencies. Runs offline. 270KB. One file.

How it was built

Built with Claude over several sessions, with a handover document carrying the plan from one session to the next. Tariq set one hard rule for the project: never invent game data. Every script, role and ability comes from the published rulebooks, and when the difficulty estimator needed a formula from the Mastermind's Handbook, he supplied the book rather than let it be guessed.

The latest round added a 20-step undo, full game export and import, configurable intrigue limits, a notes screen for each time loop, and script validation. Tariq had the difficulty estimator tried with real clicks, and its scores were checked against hand calculations.

Tech stack: Vanilla HTML · CSS · JavaScript · No dependencies · 270KB
