Self-hosted · Raspberry Pi 5

Most smart home systems rent you your own data. This one doesn't.

Kitchen Hub is a self-hosted kitchen management system built on a Raspberry Pi 5 and mounted on a fridge. It tracks live inventory through Grocy, suggests recipes based on what's in stock, matches shopping list items against real-time Flipp flyer deals from local stores, and displays the day's calendar and weather — all from a custom-built touchscreen dashboard in vanilla HTML, CSS, and JavaScript.

Voice commands run entirely on-device using faster-whisper. No audio leaves the home network. Say "I used 2 eggs" and the inventory updates. Say "Add milk to the shopping list" and it's there.

The dashboard also keeps a kitchen timer with a stopwatch beside it, for the things you time up rather than down. The screen stays awake while something is playing fullscreen, so a video doesn't go dark halfway through. A Restart and Shut Down option sits in the kiosk menu, so the Pi can be rebooted or powered off from the touchscreen without a keyboard, and the system keeps its logs across restarts so a problem can still be traced after a reboot.

A Tea tile drives a Bluetooth tea brewer from the dashboard. Brews can be scheduled ahead or started with Brew now, and the hub keeps a 30-minute gap between brews, with a Brew anyway button to override it. The label printer also gained size presets, calibrated from a printed test card so text lands where it should.

Built with Docker, Flask, Nginx, Home Assistant, Grocy, Mealie, and Tailscale for remote access. Full rebuild from backup takes under 30 minutes.

How it was built

Tariq designed the system and chose the hardware, then directed Claude to write the software: a first build in a Claude chat, followed by Claude Code sessions from late August to late October 2026. He picked the parts himself, from the Pi 5 and its cooler to the fridge-door touchscreen and a budget barcode scanner, and decided what to build next from daily use.

Most of the work came from using it in the kitchen and reporting back exactly what went wrong. There was no keyboard to type a label, so it got an on-screen keyboard. Label printing took almost a minute, so it was sped up and given a progress bar. Lifting a finger after a scroll opened whatever icon sat underneath, so that gesture was removed. Every fix was tested on the real device before the next one started.

The tea brewer came with only a phone app, so Tariq had Claude work out its Bluetooth commands by reading that app's code, then build the brewer controls into the hub. The first real brew was run with him standing at the machine, and he tested Brew anyway himself before calling it done.

Kitchen Hub runs on a private home network and is not publicly reachable — the source is on GitHub.
